# Atomic models: original Bohr motion and clearer classroom controls

The Bohr view restores continuous circular motion, Run/Pause/Reset, automatic transitions, and manual target-n selection. Radial transitions and incoming/outgoing radiation use straight lines. Incoming radiation precedes excitation; outgoing radiation is created only after a downward transition. This is a teaching animation, not a literal continuous trajectory through allowed quantum energies.

Classroom view retains model, speed, atomic number, zoom/Fit, screening, magnetic field and the Physics options menu. Options include spin, fine structure, Zeeman splitting, spectrum and visibility toggles. Live energies, signed energy change, photon energy, frequency, wavelength, radius and speed remain alongside the diagram. Zoom and drag affect the atom drawing.

Electron shielding was added following clarification; it was absent from the supplied original. The chosen constant sigma gives Zeff = Z - sigma. This hydrogenic approximation updates binding energies, radii, speeds and transition wavelengths. It is not a many-electron or Slater-rule calculation.

Normal Zeeman splitting responds to B through shifts m mu_B B. Fine-structure separations use a hydrogenic approximation. Their enlarged level drawings are separate illustrations, not a combined spin-orbit/Lande-factor calculation. The spectrum includes an enlarged normal-Zeeman triplet illustration. UV and IR rays use false colour.

Verification covers motion, transitions, shielding, field dependence, fine structure, controls, calculation rendering and production compilation. Browser checks use the actual components in a local test harness; they do not verify a deployed Vercel build.
